# ⚡ QUICK DEPLOY: 3 Steps to Live Website

## 🎯 **STEP 1: GitHub (2 minutes)**
1. Go to: https://github.com/new
2. Repository name: `ai-learning-platform`
3. **LEAVE ALL BOXES UNCHECKED**
4. Click **Create repository**
5. Copy these commands:

```bash
git init
git add .
git commit -m "Deploy"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ai-learning-platform.git
git push -u origin main
```

6. Open VS Code terminal in your project folder
7. Paste commands one by one

## 🎯 **STEP 2: Vercel (1 minute)**
1. Go to: https://vercel.com/new
2. **Sign up with GitHub** (one click)
3. Click **Import Project**
4. Find `ai-learning-platform` → **Import**
5. Click **Deploy** (don't change settings)

## 🎯 **STEP 3: Test (1 minute)**
1. Wait for green ✅ "Deployment complete"
2. Click **Visit**
3. Test at: `https://ai-learning-platform.vercel.app`
